Content

Let's Go Padres (Padres Song Remix) is on the Scoobert Doobert channel. YouTube dates the upload May 10, 2021. It runs 1:48. The description says 91X gave him the idea to remix classic San Diego songs, and that Reddit user janky85 asked for "Let's Go Padres."

Let's Go Padres (Remix) is a separate SoundCloud upload. SoundCloud's timestamp is 2021-05-11T03:50:30Z. It runs 1:37. The description there is: "Uploaded cuz u/GodFrusciante willed it so!" Dj Holmes left a comment at 1:22: "Thanks for the Track!"

Same week, two files. Same San Diego run as the Chargers remix.
